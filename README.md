# برنامج المصروفات اليومية (Daily Expense Tracker)
برنامج سطح مكتب مكتوب بلغة Python باستخدام Tkinter وقاعدة بيانات SQLite لتتبع المصروفات الشخصية اليومية.

## المميزات:
- إضافة وحذف المصروفات.
- تصنيف المصروفات (طعام، مواصلات، فواتير، إلخ).
- حساب إجمالي المصروفات بشكل آلي.
- تصدير البيانات إلى ملف Excel.

## التثبيت والتشغيل:
قم بتثبيت المكتبات المطلوبة أولاً:
```bash
