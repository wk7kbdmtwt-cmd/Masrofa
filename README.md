# برنامج المصروفات اليومية (Daily Expense Tracker)

برنامج سطح مكتب مكتوب بلغة Python باستخدام Tkinter وقاعدة بيانات SQLite لتتبع المصروفات الشخصية اليومية[span_0](start_span)[span_0](end_span).

## المميزات:
- إضافة وحذف المصروفات[span_1](start_span)[span_1](end_span).
- تصنيف المصروفات (طعام، مواصلات، فواتير، إلخ)[span_2](start_span)[span_2](end_span).
- حساب إجمالي المصروفات بشكل آلي[span_3](start_span)[span_3](end_span).
- تصدير البيانات إلى ملف Excel[span_4](start_span)[span_4](end_span).

## التثبيت والتشغيل:
قم بتثبيت المكتبات المطلوبة أولاً عبر تنفيذ الأمر التالي في موجه الأوامر:

`pip install -r requirements.txt`

ثم قم بتشغيل البرنامج:

`python app.py`
